Using Ricci Flow Lab

  1. Choose a mesh

    Select a built-in shape under Input mesh, or use Open PLY / OBJ to load a triangle mesh from your device. The reader accepts ASCII PLY, little- and big-endian binary PLY, and OBJ. For a polygon mesh, triangulate its faces before importing.

  2. Set the target curvature

    At 0% strength, the target equals the input curvature. At 100%, the solver uses the selected target. The angle defects on each connected component sum to 2πχ, where χ is its Euler characteristic.

    For a starting pattern, choose a Paint preset and click Apply. The Change colours show where the pattern raises or lowers the input curvature. Choose Target to see the absolute angle defects. A preset replaces the current painting. Brush over it or use Undo to restore the previous painting. Patterns also work on imported meshes.

    Choose Paint on mesh to set signed angle defects in radians at 100% strength. Enter a value and drag across the surface. Each edge ring adds one layer of neighboring vertices. Choose Erase to release painted vertices. Unpainted vertices share the adjustment needed to preserve their component’s total curvature. Target CSV files use zero-based vertex IDs.

    While painting, hold Shift and drag to rotate, or select Orbit on a touch screen. Scroll or pinch to zoom.

  3. Run the solver

    Inversive-distance circle packing determines the edge lengths. A damped Gauss–Newton solve fits a 3D shape to those lengths. Enable intermediate previews to review individual iterations in the shape history.

Under Solver settings, a positive bending weight favors the selected dihedral angle across each interior edge. Choose Flat to encourage adjacent triangles to lie in the same plane, or Input dihedral angles to preserve the folds of the input mesh.

Curvature error measures how closely the intrinsic angle defects match the target. Relative edge-length error measures how closely the reconstructed edges match the intrinsic lengths. When reviewing results, mesh colours show the angle defects of the displayed shape.

Use Check vertex stars to look for local pinches in the triangles around each interior vertex of the displayed shape. Boundary vertices and global self-intersections fall outside the scope of this check.

Drag to rotate. Scroll or pinch to zoom. With the viewer focused, use the arrow keys to rotate and the plus and minus keys to zoom.
